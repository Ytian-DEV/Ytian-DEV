# Assets Directory

This directory contains images and media files for my GitHub profile.

## File Structure
- `banner.png` - Profile header banner
- `projects/` - Project screenshots and demos
- `social/` - Social media icons and assets

## Recommended Image Sizes
- Banner: 1200x300 pixels
- Project screenshots: 800x400 pixels
- Icons: 64x64 pixels

## How to Add Images
1. Upload your images to the appropriate folders
2. Reference them in README.md like: `![Alt Text](./assets/folder/image.png)`
