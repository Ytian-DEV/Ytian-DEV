# Christian Earl James Boyles

Full-stack developer and multimedia producer from Baybay City, Leyte.  
I build web apps with TypeScript, React, Next.js, and Postgres, and do UI design, video editing, and motion work alongside development.

Right now I'm working on [Amaranth](https://amaranth-iota.vercel.app), the student publication site for Visayas State University, and [MapaGuapa](https://mapaguapa.vercel.app), a boarding house map for VSU students built with Viscan YouthMappers.
